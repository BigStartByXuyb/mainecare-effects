## What changed

- **Default screen is the liquid-glass showcase.** Bright generated bokeh wallpaper, the
  `Upstream` preset with `overLight=true`, clear glass card and companion surfaces. The v21
  Obsidian gallery is the second tab (`V21`, `screen=obsidian`); deck is the third.
- **README first image** is the showcase; the old dark sample no longer leads the repository.
- **Upstream overLight blur fixed.** The source formula is `(overLight ? 12 : 4) + blurAmount *
  32` px → 14px overLight / 6px dark for the default `blurAmount=.0625`. Upstream surfaces now
  derive the effective blur from `LiquidGlassParams.liquidBlurRadiusDp`; v21 keeps its explicit
  radius. This is the main fidelity fix in 0.1.3.
- **A/B harness** accepts `--es bg showcase` so the real React component and the Android card
  are compared over the same bright wallpaper.
- **Refraction evidence** with displacement on/off and edge crops; see
  `docs/liquid-glass-0.1.3.md`.

Presets: `Card`, `Advice`, `MealFront`, `Insight`, `Dock`, `SoftControl`, plus `Upstream`.
`MaineGlassCard` remains the only App seam.

## Measured result

Against the real `liquid-glass-react@1.1.1` component over the showcase wallpaper, the card
region is **MAE 3.51 / SSIM 0.951** (inner 3.24 / 0.953). This is the closest A/B measured so
far; the overLight blur fix lowered card MAE from 6.84 and raised SSIM from 0.902 against the
same reference. Light 390/430 A/B improved to 7.60 / 6.64 MAE; dark is unchanged at
16.52 / 11.63 because its 6px blur was already correct.

The v21 canonical gate is unchanged and still **PASS**: static SSIM 0.99548 / MAE 0.421 /
0.414% over Δ5; displacement 0.99542 / 0.416 / 0.346%.
